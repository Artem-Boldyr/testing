1. Відповіді на контрольні запитання

Різниця між unittest.TestCase та функцією pytest:

Структура: У unittest тести обов'язково є методами всередині класів, що успадковуються від unittest.TestCase. У pytest тести — це звичайні автономні функції.

Перевірка умов: unittest потребує спеціальних методів (self.assertEqual, self.assertRaises), тоді як pytest використовує стандартну та лаконічну конструкцію Python assert.

Фікстури: unittest керує даними через прив'язані методи setUp/tearDown, а pytest надає гнучкі та перевикористовувані @pytest.fixture з можливістю налаштування області дії (scope).
